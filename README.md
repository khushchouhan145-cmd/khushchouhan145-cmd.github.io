# Khushi Chouhan — AI/ML Portfolio

A responsive personal portfolio website showcasing Khushi Chouhan's AI/ML learning journey and four DecodeLabs internship projects.

## Files
- `index.html` — portfolio content and project case studies
- `style.css` — responsive dark UI, cards, layout and animations
- `script.js` — mobile navigation

## Run locally
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Projects featured
1. DecodeBot — Rule-Based AI Chatbot
2. Iris Flower Classification using KNN
3. AI Recommendation Logic using TF-IDF + Cosine Similarity
4. Image/Text Recognition using OpenCV + Tesseract OCR
